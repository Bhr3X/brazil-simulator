# CrazyGames marketing media

These assets follow the current CrazyGames cover and preview-video requirements.

## Covers

- `covers/cover-landscape-1920x1080.png`
- `covers/cover-portrait-800x1200.png`
- `covers/cover-square-800x800.png`

All three use consistent original key art. The only writing is the game title along the bottom. The top-left quadrant contains no writing, logo, badge, or interface.

## Preview videos

- `videos/preview-landscape-1920x1080.mp4`
- `videos/preview-portrait-1080x1620.mp4`

The silent 18-second edit begins with the matching cover, then cuts through achievable gameplay states: the espresso approach, awkward frothing, jumping for forage, the barbecue confrontation, and early rally movement. It excludes the player decision, final speech, meteor, impact, and ending card.

## Cover generation prompt

The covers were generated separately for each aspect ratio with the built-in image-generation tool. The shared direction was: original promotional key art using the current red T-Rex identity and forest as references; green knit beanie, oversized black glasses, plaid overshirt, beige leaf tote, tiny arms and expressive physical comedy; premium sculpted arcade-creature treatment; spoiler-free espresso and barbecue setup; exact title `VEGAN T-REX` along the bottom only; no writing in the top-left quadrant; no other text, UI, border, platform logo, watermark, meteor, impact, ending, decision, or violence.

Sources: [CrazyGames game-cover requirements](https://docs.crazygames.com/requirements/game-covers/) and [gameplay requirements](https://docs.crazygames.com/requirements/gameplay/).
