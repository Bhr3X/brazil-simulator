# Brazil Simulator // Sobrevivência BR — Canonical Architectural Invariants (I1–I13)

- **I1: Single Source of Truth Build**: `pirituba_standalone.html` is strictly generated by `node build.js`. No manual modifications are permitted to the standalone bundle.
- **I2: Deterministic Seeded PRNG**: All gameplay, character generation, social roulette, encounter rolls, and physical kick simulations flow strictly through `Rng.js` (Mulberry32). The active seed is stored, reproducible, and surfaced in state and URL params (`?seed=`). Purely cosmetic shader noise and procedural audio synthesis noise generators are excluded from gameplay state determinism.
- **I3: Sim-Time Master Clock**: 600 real-world seconds equal 24 in-game hours (06:00 to 06:00 next day). Tab visibility pauses clock. All time-gated probabilistic events scale per sim-second, not per animation frame. Manual time cycling advances time forward-only during active runs.
- **I4: Atomic State Mutation & Integer Centavos**: Currency is stored in integer centavos (R$ 1,00 = 100). Stats (bucho, sanidade, perigo, ginga) are strictly clamped integers in [0, 100]. All state mutations pass through `GameState.apply(deltas, reason)`.
- **I5: Raycast Interaction Predicate Parity**: The `[E]` interaction HUD prompt displays if and only if the exact predicate required to execute the interaction is satisfied. Prompts are hidden at run end and during modals.
- **I6: Modal Input Freeze**: With any dialogue or modal open (Dialog, Street View, Social Roulette, End Screen), player movement, camera rotation, kick impulses, and interaction key triggers are completely frozen via multi-source DOM resolution (`controls.refreshFreeze()`). Closing one modal never unfreezes the player if another modal remains active.
- **I7: Audio Context on User Gesture**: Web Audio context initializes exclusively upon user gesture (e.g. roulette selection click).
- **I8: Street View Feature Parity**: Google Street View modal (`[V]`) at Edgar Facó x Paula Ferreira remains fully functional alongside the roguelite engine.
- **I9: Dynamic Physical Props**: Rigid bodies (soccer ball, beer cans) feature AABB ground collision, restitution, velocity damping, kick impulse with vertical reach/cooldown guards, and audio callbacks.
- **I10: Continuous 24h Solar Cycle**: Celestial lighting keyframe interpolation across 24h with a dedicated ASCII readability ambient floor during night hours.
- **I11: DOM Survival HUD with pt-BR Formatting**: In-game survival dashboard rendered in DOM, formatted in Brazilian Portuguese with `Intl.NumberFormat('pt-BR', { style: 'currency', currency: 'BRL' })`.
- **I12: Data-Driven Spatial Zones**: Authoritative spatial boundaries and operating hours are governed by `src/world/Zones.js` (AABB tables), avoiding ad-hoc coordinate branches.
- **I13: Unidirectional Module Hierarchy**: `src/engine/` and `src/world/` must never import from `src/game/`. Dependencies flow strictly from top-level orchestration (`main.js`, `GameManager.js`) down to systems.
