# One Local Day — Architecture Atlas

Open **index.html** in a browser. Keep the accompanying files in the same folder.

The atlas contains:

- Parallel startup lanes from location confirmation, followed by seven synchronized lanes across a 15-minute run.
- Three interactive Archify diagrams: engine architecture, startup sequence, and action-to-radio feedback.
- Eighteen system contracts, deterministic/AI ownership, world laws, vehicle streaming, seeds, failure paths, and a variable-cost calculator.
- Prototype evidence and linked primary sources. Timings, cadence and cost are explicitly targets or estimates.

## Design decisions

Use prepared regional art and geographic data with fresh per-run writing and music. Enter once the character and a safe opening are ready. Maintain a rolling reserve while the player moves. AI proposes structured content; code validates and resolves effects.

Keep a shareable scenario manifest with saved generated content and named random streams. Different player choices yield different attempts. Exact cross-device physics replay is not assumed.

Target desktop and mobile browsers, first/third person, and cars/bikes. The design is stack-independent. High-fidelity worldwide coverage remains a data and licensing dependency: standard Google Maps terms do not provide a general right to derive a new playable world from Street View.
